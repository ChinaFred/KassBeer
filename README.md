# Kass'Beer

Application de brassage amateur pour un brasseur et quelques amis : recettes et calculs
(densités, degré, IBU, EBC, coût), profils d'équipement (cuves, Grainfather), déroulé du
jour de brassage hors ligne, suivi des brassins. Elle remplace des fiches Excel.

Android (APK) et web. Flutter, Firebase (Auth Google, Firestore, Hosting), calculs dans un
paquet Dart pur. Comptes sur invitation.
